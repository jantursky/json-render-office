## Reading the tables

- **Nullable** props must still be present in the element. Write `null` to use the default, because the catalogs are strict.
- Limits such as "up to 90 characters" or "1 to 7 items" are enforced by `validateProps`, not by the renderer. A spec over a limit still renders.
- Every element has `type`, `props` and `children`. Components that take no children use `"children": []`.
- The examples show an element on its own. Put the keys of its children in `children`, and add each child to `elements`.
