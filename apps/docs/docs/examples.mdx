The previews on this page run the example files of the demo app, so the docs and the demo cannot drift apart. The same files are in `apps/example/src/examples`. Open the **Code** tab of a preview to read it.

## Preview

The web renderer of `json-render-report` draws a fixed report spec. The same spec is what the other two examples use.

## Streaming

The spec arrives as JSONL patches, two lines at a time, and the page fills in as `createSpecStreamCompiler` applies them. See [Streaming](/streaming).
